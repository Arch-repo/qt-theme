# Anto426 Qt theme

Canonical renderer for the wallpaper palette and the shell's shared material.
One theme covers Qt5/Qt6 Widgets through Kvantum plus native style sheets, and
Qt5/Qt6 Quick Controls through a shared `Anto426` style made of native Templates.

```sh
python3 palette/render.py --palette palette/default.json \
  --material palette/material.json --output build/theme
python3 scripts/verify-palette.py
```

The renderer emits 21 QPalette roles for Qt5 and older Qt6, or 22 for Qt6.6+
including Accent. PlaceholderText stays opaque; `--qt6-legacy` checks the earlier
role layout. Widgets require Qt5.12+; the Quick style requires Qt5.15+ or Qt6.
Python 3.10+ is the only rendering dependency.

## Shared controls

`widgets.qss.in` covers fields, buttons, check/radio indicators, spin controls,
combo popup/arrow, sliders, progress, scrolling, views/headers, tabs, menus,
toolbars, groups and dock headers. Complex controls include their subcontrols;
changing just a background would otherwise retain unrelated native geometry.
Generated SVG indicators use the same foreground and selected-text roles.
The KvArcDark base remains the fallback for other Widgets; every fixed RGB color
in its SVG is mapped, including previously retained blue focus colors.

`quick/Anto426` supplies 47 native control types, one file per type. Shared
Surface, ButtonContent, ToggleIndicator, ControlText and SliderThumb primitives
keep state rendering consistent. Native Qt Templates retain keyboard, pointer,
accessibility and model behavior. Menus, dialogs, popup fields, scroll views,
tabs, range sliders and indicators use the same palette, radii and surfaces.
Fusion supplies types added by newer Qt versions that this style does not own.

Colors, material alpha, spacing and geometry are evaluated from the shell's
`application-material.json`; no parallel palette is generated by this repository.
`palette/material.json` is the standalone reference snapshot. `scripts/build-quick.py`
creates a reproducible style archive for immutable, checksum-pinned delivery.

## Desktop installation

The dotfiles installer selects Kvantum and preserves fonts and foreign QSS files.
`QT_STYLE_OVERRIDE` is cleared so qt5ct/qt6ct can supply the complete palette.
Current Qt6ct accepts the `qt5ct` platform key used by Qt5ct. The generated
`qtquickcontrols2.conf` selects Anto426 with Fusion fallback; Quick files are
installed in `anto-desktop/qml` under XDG data. Qt6 uses `QML_IMPORT_PATH`;
Qt5 also receives `QML2_IMPORT_PATH` and `QT_QUICK_CONTROLS_STYLE_PATH`.
The Qt5 style-path mechanism was removed in Qt6, so both lookup paths matter.

Kvantum paints translucent backgrounds without fading text; Quick surfaces use
background alpha directly. Menus and tooltips use a readable popover material.
Existing applications may require reopening after installing the style.
Application-owned QSS/palettes, compile-time Quick styles, custom-drawn controls
and isolated runtimes may override system preferences. This does not replace
application code or guarantee styling of every Qt application.

Runtime checked with Qt5/Quick 5.15.19, Qt6/Quick 6.11.2 and Kvantum 1.1.8:
painted focus borders, native keyboard/pointer actions, combo popup selection,
47-type Quick creation without QML warnings, and compositor background response.
Earlier Qt6 has artifact checks, not an executed historical runtime.
